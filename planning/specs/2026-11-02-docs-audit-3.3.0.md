# Documentation audit for 3.3.0

**Date:** 2026-11-02
**Status:** Complete; PR 43, ships in 3.3.0

The audit covers every tracked Markdown and reStructuredText page, the docstrings that `help()`
and the reference pages show, and the comments in the library's source. Test-suite code comments
and docstrings are outside it, apart from those of `strategies.py`, `test_provn_corpus.py`,
`test_json_schema.py` and `test_xml_schema.py` that the audit changed. The rules applied are
section 3 of [the documentation restructure spec](2026-10-23-docs-restructure-design.md), the
Changelog entries and Documentation rules, now in `.claude/rules/changelog.md` and
`.claude/rules/documentation.md`, and the style brief of
[the 3.1.1 review](2026-09-10-docs-review.md). Planning specs are historical records and their
bodies are untouched.

Behaviour defects this PR leaves unchanged.

- A PROV-O read of an entity or agent that shares an identifier with a relation raises `StopIteration`, not `ProvRDFException` ([#743](https://github.com/trungdong/prov/issues/743)).
- A bundle keeps a resolved name after its document binds a prefix, so two bundles in the same state can give one string two names ([#744](https://github.com/trungdong/prov/issues/744)).
- `prov-convert` leaves its output file empty when the writer fails, so converting a file onto itself destroys it ([#745](https://github.com/trungdong/prov/issues/745)).
- `prov_to_graph(bundle)` raises a bare `AttributeError` ([#746](https://github.com/trungdong/prov/issues/746)).
- `copy.copy` of a `NamespaceManager` shares its namespace index and map (`_uris_by_length` and `_uri_map`) with the original, so `add_namespace` on the copy changes the original ([#747](https://github.com/trungdong/prov/issues/747)).
- `get_asserted_types` is annotated `set[QualifiedName]` and returns `str` and `int` values too ([#748](https://github.com/trungdong/prov/issues/748)).
- `serialize()` ignores an unknown option for `rdf`, `xml` and `provn`, where the JSON writers raise `TypeError` ([#749](https://github.com/trungdong/prov/issues/749)).
